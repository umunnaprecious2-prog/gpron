# System Design Skill

## Purpose
Design clean and scalable system architecture.

## When to Use
Use before coding or when restructuring systems.

## Rules
- Design before coding
- Separate responsibilities
- Keep modules organized
- Plan for scalability

## Steps
1. Define problem
2. Define scope
3. Identify components
4. Design data flow
5. Choose stack
6. Assign responsibilities

## Output
Structured system architecture with clear components and flow
