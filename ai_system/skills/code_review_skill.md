# Code Review Skill

## Purpose
Improve code quality and maintainability.

## When to Use
Use after writing or modifying code.

## Rules
- Check for simplicity and readability
- Identify performance issues
- Check for security risks
- Ensure consistency with project structure

## Steps
1. Review code structure
2. Check naming and readability
3. Identify redundant logic
4. Check error handling
5. Check security issues
6. Suggest improvements

## Output
Clean review with actionable improvements
