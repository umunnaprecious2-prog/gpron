# Research and Documentation Skill

## Purpose
Turn raw information into structured knowledge.

## When to Use
Use when working with documentation, APIs, or new tools.

## Rules
- Extract key information only
- Organize knowledge clearly
- Avoid unnecessary detail

## Steps
1. Identify source material
2. Extract key points
3. Structure information
4. Summarize clearly
5. Highlight important details

## Output
Clear, structured, usable knowledge
