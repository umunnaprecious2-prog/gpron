# Debugging Skill

## Purpose
Identify and fix issues efficiently.

## When to Use
Use when errors occur or systems fail.

## Rules
- Do not guess
- Check error messages
- Check .env first
- Verify dependencies

## Steps
1. Identify error
2. Classify error
3. Check environment variables
4. Verify dependencies
5. Trace logic
6. Fix and test

## Output
Resolved issue with clear explanation
