# Prompt Engineering Skill

## Purpose
Turn any idea into clear, structured, executable instructions.

## When to Use
Use when starting tasks, refining prompts, or structuring instructions.

## Rules
- Define the goal clearly
- Specify input and output
- Break tasks into steps
- Avoid ambiguity

## Steps
1. Understand the task
2. Define the objective
3. Identify inputs and outputs
4. Break into steps
5. Add constraints

## Output
Clear, structured prompt Claude can execute effectively
