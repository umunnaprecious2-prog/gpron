# Product Thinking Skill

## Purpose
Ensure the product solves a real problem.

## When to Use
Use when defining features or planning products.

## Rules
- Focus on user problem
- Avoid unnecessary features
- Prioritize value
- Keep it simple

## Steps
1. Identify user
2. Define problem
3. Define solution
4. Select core features
5. Remove extras

## Output
Clear and valuable product direction
