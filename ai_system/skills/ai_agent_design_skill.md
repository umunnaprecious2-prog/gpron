# AI Agent Design Skill

## Purpose
Design intelligent agents that can reason and act.

## When to Use
Use when building AI systems or automation workflows.

## Rules
- Define clear agent role
- Define inputs and outputs
- Use tools only when needed
- Keep behavior predictable

## Steps
1. Define agent role
2. Define input and output
3. Select tools
4. Design reasoning flow
5. Add memory if needed

## Output
Well-defined AI agent structure and workflow
