# Codebase Exploration Skill

## Purpose
Understand and document an entire system quickly.

## When to Use
Use when entering a new project or understanding unfamiliar code.

## Rules
- Do not skim, explore deeply
- Identify relationships between components
- Focus on architecture and data flow

## Steps
1. Identify main modules
2. Analyze structure
3. Trace data flow
4. Identify key files
5. Identify APIs and database usage
6. Document findings clearly

## Output
Structured system understanding and documentation
