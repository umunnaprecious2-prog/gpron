# API Design and Integration Skill

## Purpose
Build and connect APIs effectively.

## When to Use
Use when creating endpoints or integrating services.

## Rules
- Keep endpoints clear
- Standardize requests/responses
- Handle errors properly
- Secure access

## Steps
1. Define API purpose
2. Design endpoints
3. Define request/response
4. Add authentication
5. Test integration

## Output
Reliable API design or integration
