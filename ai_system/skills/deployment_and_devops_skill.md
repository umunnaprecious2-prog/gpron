# Deployment and DevOps Skill

## Purpose
Ensure system runs correctly in production.

## When to Use
Use before deployment or during environment setup.

## Rules
- Separate environments
- Use .env variables
- Monitor logs
- Test deployment

## Steps
1. Prepare environment variables
2. Configure deployment
3. Deploy system
4. Monitor logs
5. Fix issues

## Output
Stable deployed application
