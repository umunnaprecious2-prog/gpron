# Project Execution Skill

## Purpose
Ensure structured and complete project execution using Claude as the main development assistant.

## When to Use
Use at the start of every project and throughout the entire build process.

## Rules
- Follow the workflow step by step
- Do not skip important setup stages
- Use Claude for reasoning, generation, and debugging
- Test at each stage before moving forward
- Save progress consistently

## Steps
1. Plan the app
2. Decide the stack
3. Explore possibilities and brainstorm with Claude
4. Choose a starter template
5. Set up the project environment (Replit, local, or preferred IDE)
6. Create the database
7. Connect backend and database
8. Use Claude to generate core system components
9. Test the system step by step
10. Refine and debug using Claude
11. Connect GitHub and save versions
12. Prepare for deployment
13. Deploy the application
14. Test the live system
15. Iterate and improve using Claude

## Output
A fully built, tested, and deployed project developed with a structured workflow using Claude
