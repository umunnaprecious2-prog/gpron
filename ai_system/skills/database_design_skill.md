# Database Design Skill

## Purpose
Design scalable and efficient data structures.

## When to Use
Use when creating or modifying databases.

## Rules
- Keep schema simple
- Avoid duplication
- Use proper relationships
- Plan for scale

## Steps
1. Identify entities
2. Define relationships
3. Choose DB type
4. Design schema
5. Add indexes

## Output
Clean and scalable database schema
